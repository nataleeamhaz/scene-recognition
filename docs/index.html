🏠 Room Design Recommender

A personal project for getting AI-assisted room design feedback — upload a photo of your space and get furniture detection, style analysis, and design inspiration.

What it does:

  • Detects furniture and objects in a room photo
  • Analyzes style, mood, and color palette
  • Suggests actionable design improvements
  • Surfaces related design inspiration via Pinterest

This is an individual hobby project, not a commercial product or company. Source code is available on GitHub.
